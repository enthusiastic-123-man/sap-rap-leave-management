# sap-rap-leave-management
leave-management
🌴 SAP Fiori RAP - Employee Leave Management System
An end-to-end Employee Leave Management System built with SAP ABAP Cloud and the RESTful Application Programming Model (RAP).

✨ What It Does
📅 Leave Requests: Clean Fiori UI for employees to submit time-off applications.

⚡ Real-Time Quota Checks: Automatically validates date ranges and remaining leave balances.

✅ Manager Approvals: One-click "Approve" and "Reject" custom actions.
